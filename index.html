Требуется Telegram Username

Для использования приложения установите имя пользователя в настройках Telegram.

Как установить Username

  1. Откройте Telegram.
  2. Перейдите в Настройки (⚙️).
  3. Нажмите на свой профиль.
  4. Выберите Имя пользователя.
  5. Введите желаемый username и сохраните.
